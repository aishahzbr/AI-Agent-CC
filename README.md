# AI Agent CC

A simple command-line AI chat agent built with the Anthropic Claude API.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Set your API key:
   ```
   cp .env.example .env
   ```
   Then edit `.env` and add your `ANTHROPIC_API_KEY`.

## Run

```
python agent.py
```

Chat with the agent in your terminal. Type `exit` or `quit` to stop.
